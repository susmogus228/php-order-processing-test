# Обработка заказов

Скрипт для PHP 8.1 или новее. Не требует библиотек, веб-сервера или базы данных.

## Запуск

Из папки с файлом `orders.php`:

```bash
php orders.php
```

Без аргументов используются заказы из условия задания, встроенные в скрипт. Для собственного JSON-файла в кодировке UTF-8:

```bash
php orders.php orders.json
```

Файл должен содержать JSON-массив объектов с полями `id`, `customer`, `amount` и `status`. В Windows при необходимости укажите полный путь к `php.exe`. Консоль должна поддерживать UTF-8.

## Пример результата

```text
Количество оплаченных заказов: 3
Общая сумма оплаченных заказов: 4500
Самый дорогой оплаченный заказ: № 103 на сумму 3000
Заказов по статусам: paid — 3, pending — 1
```

Дополнительное задание: **вариант Б**, подсчёт количества заказов по статусам. При отсутствии оплаченных заказов сумма и количество равны нулю, а самый дорогой заказ отсутствует. При одинаковой максимальной сумме выбирается первый заказ в исходном списке.

## Проверка данных и ошибки

Все заказы проверяются до расчёта. При любой ошибке программа выводит сообщение в стандартный поток ошибок (`stderr`), завершает работу с кодом `1` и не выводит частичную статистику. Успешное завершение — код `0`.

- Некорректный JSON: выводится ошибка декодирования. Корнем должен быть массив; каждый элемент должен быть объектом.
- Отсутствует обязательное поле: выводятся номер элемента в массиве (начиная с 1) и имя поля.
- `amount` должен быть JSON-числом, конечным и неотрицательным. Строки, `null`, логические значения и отрицательные числа не принимаются; `0` допускается.
- Допустимыми статусами считаются `paid` и `pending`, поскольку они присутствуют в условии. Другой статус считается неизвестным и вызывает ошибку. Список статусов можно расширить при изменении требований.
- `id` должен быть положительным целым числом, `customer` — непустой строкой. Лишние поля не мешают обработке.
- Если файл не существует или не читается, выводится сообщение об ошибке. Пустой массив корректен.

Дробные значения допустимы и суммируются стандартной арифметикой PHP с плавающей точкой. Для реальной финансовой системы с требованием точного округления лучше определить валюту и правила округления и использовать целые минимальные единицы или десятичную арифметику.

Документация PHP: [json_decode](https://www.php.net/manual/en/function.json-decode.php), [JsonException](https://www.php.net/manual/en/class.jsonexception.php).
